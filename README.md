# 어른이집

보육교사가 직장 고민을 안전하게 나누고, 실무 자료와 이직 정보를 얻는 인증형 익명 커뮤니티입니다.

## 기술 스택

- Next.js, React, TypeScript
- Supabase Auth, PostgreSQL, Storage

## 로컬 실행

```bash
cp .env.example .env.local
npm install
npm run dev
```

`.env.local`에 Supabase 프로젝트 URL과 publishable key를 입력해야 Supabase 기능을 사용할 수 있습니다.

자세한 제품 방향과 문서 버전은 [프로젝트 문서](./docs/README.md)를 참고하세요.
