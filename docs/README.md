## 버전 관리 규칙

- 파일명은 `어른이집_서비스기획서_v{버전}.md` 형식을 사용합니다.
- 내용을 변경할 때 기존 파일은 수정하지 않고 복사해 새 버전을 만듭니다.
- 작은 보완은 `v0.2`, `v0.3`처럼 올립니다.
- 범위나 전략이 크게 바뀌면 `v1.0`, `v2.0`처럼 올립니다.
- 새 버전을 만들면 위 표의 맨 위에 버전, 작성일, 변경 요약을 추가합니다.
- 세부 수정 이력은 Git 커밋으로 확인합니다.
