# 어른이집 화면 설계

> 문서 버전: v0.1  
> 문서 상태: 모바일 웹 중심 초기 설계  
> 작성일: 2026-08-21

## 1. 설계 목표

- 처음 방문한 사용자가 서비스의 성격을 즉시 이해한다.
- 로그인하지 않아도 공개 게시글을 읽고 서비스의 가치를 경험한다.
- 가입한 교사는 두 번 이내의 선택으로 고민을 작성한다.
- 익명성과 교사 인증 상태를 화면에서 명확하게 구분한다.
- 모바일에서 먼저 설계하고 넓은 화면에서는 콘텐츠 폭만 확장한다.

## 2. 핵심 사용자 흐름

### 검색을 통한 첫 방문

`검색 결과 → 공개 게시글 상세 → 다른 교사의 답변 확인 → 가입 안내 → 교사 인증`

### 고민 작성

`홈 → 글쓰기 → 속풀이방 선택 → 원하는 반응 선택 → 작성 → 익명 확인 → 게시`

### 실무자료 탐색

`홈 → 교무실 → 연령·업무 필터 → 자료 상세 → 저장 또는 다운로드`

### 이직정보 탐색

`홈 → 이직반 → 지역·시설유형 선택 → 후기 확인 → 저장`

## 3. 정보 구조

```text
어른이집
├── 홈
│   ├── 속풀이방
│   ├── 교무실
│   └── 이직반
├── 검색
├── 글쓰기
├── 저장
└── 내 정보
    ├── 교사 인증
    ├── 내가 쓴 글·댓글
    ├── 알림
    ├── 차단 관리
    └── 설정
```

## 4. 공통 내비게이션

### 모바일

- 상단: 로고, 검색, 알림
- 하단: 홈, 검색, 글쓰기, 저장, 내 정보
- 글쓰기는 하단 중앙에서 가장 명확하게 표시한다.

### 데스크톱

- 왼쪽: 로고와 주요 메뉴
- 가운데: 게시글 피드 또는 상세 콘텐츠
- 오른쪽: 로그인·인증 상태와 인기 주제
- 본문 최대 폭을 제한해 긴 글의 가독성을 유지한다.

## 6. 핵심 화면 설계

### H-01 홈 피드

1. 상단에 서비스 로고, 검색, 알림을 둔다.
2. `속풀이방`, `교무실`, `이직반` 탭으로 공간을 전환한다.
3. 첫 카드에는 고민 작성 진입점을 제공한다.
4. 게시글 카드는 공간, 주제, 제목, 요약, 작성 시각, 반응 수만 표시한다.
5. 작성자의 이름 대신 인증 유형과 경력 범위만 노출한다.

### P-01 게시글 상세

1. 제목 위에 공간과 세부 주제를 표시한다.
2. `현직 인증 · 4~6년 차`처럼 신뢰 판단에 필요한 최소 정보만 보여준다.
3. 작성자가 원하는 반응을 본문 가까이에 표시한다.
4. 댓글은 `도움됐어요` 수보다 내용이 먼저 읽히게 한다.
5. 신고와 차단은 더보기 메뉴에 둔다.
6. 비회원에게는 내용을 읽은 뒤 자연스럽게 가입 안내를 제공한다.

### P-02 글쓰기

1. 게시 공간을 선택한다.
2. 속풀이방에서는 원하는 반응을 필수로 선택한다.
3. 제목과 내용을 작성한다.
4. 공개 범위를 `검색 공개`와 `회원 공개` 중 선택한다.
5. 게시 직전에 신원 노출 가능성이 있는 표현을 다시 확인하게 한다.

## 7. 콘텐츠 카드 규칙

- 제목은 모바일에서 최대 두 줄로 표시한다.
- 본문 미리보기는 최대 세 줄로 표시한다.
- 프로필 사진과 임의 닉네임은 초기 버전에서 사용하지 않는다.
- 인증 여부, 경력 범위, 게시 시각만 작성자 정보로 제공한다.
- 공감보다 `위로해요`, `도움됐어요`, `저장`처럼 의미가 분명한 반응을 사용한다.
- 조회 수는 경쟁을 부추길 수 있어 초기 피드에서 노출하지 않는다.

## 8. 익명성과 공개 범위

- 공개 글은 검색엔진에 노출될 수 있음을 작성 화면에서 명확히 알린다.
- 회원 공개 글은 검색과 비회원 접근에서 제외한다.
- 어린이집명, 실명, 연락처처럼 신원을 특정할 수 있는 표현은 작성 중 경고한다.
- 교사 인증 원본과 커뮤니티 프로필은 화면과 데이터 구조 모두에서 분리한다.

## 9. 반응형 기준

- 767px 이하: 단일 열과 하단 내비게이션
- 768~1199px: 가운데 콘텐츠 중심, 필요한 보조영역만 표시
- 1200px 이상: 왼쪽 메뉴·가운데 콘텐츠·오른쪽 보조정보의 3열
- 모바일 화면을 단순 확대하지 않고 데스크톱의 빈 공간에는 탐색 정보만 추가한다.

## 10. 우선 구현 범위

1. 홈 피드
2. 게시글 상세
3. 글쓰기
4. 로그인·가입
5. 교사 인증 상태
6. 신고

검색, 자료 다운로드, 어린이집별 후기 비교는 핵심 커뮤니티 흐름이 검증된 뒤 구현한다.

## 11. 다음 결정 사항

- 브랜드 색상과 서체
- 공개 글의 본문 노출 범위
- 익명 작성자 표기 방식
- 홈의 기본 탭
- 교사 인증 전 허용할 활동 범위
- 게시글 반응 명칭과 종류
