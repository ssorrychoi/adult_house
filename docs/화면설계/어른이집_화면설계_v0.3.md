# 어른이집 화면 설계

> 문서 버전: v0.3  
> 문서 상태: MVP UI 확정  
> 작성일: 2026-08-24

## 제품 방향

어른이집은 보육 현장에서 일하는 선생님들이 직장 고민, 실무자료, 이직 정보를 나누는 익명 커뮤니티다. 가입 시 교사 인증을 강제하지 않고 직군과 경력만 선택하면 바로 이용할 수 있다.

## 확정 정보 구조

- 선생님 이야기: 원장·동료, 학부모 관계, 업무·처우, 퇴사·번아웃
- 업무 도움: 놀이·수업, 행사 준비, 관찰일지·알림장, 학부모 상담, 평가제·행정, 특수보육
- 커리어: 채용정보, 어린이집 후기, 면접 후기, 이직 고민, 자격·교육
- 전문가 Q&A: 근로계약·급여, 휴게시간·연차, 직장 내 괴롭힘, 아동학대 대응, 기타 법률상담
- 내 정보 > 고객지원: 공지사항, FAQ, 문의하기

보육교사, 특수교사, 유치원교사는 주 카테고리가 아니라 직군 필터로 사용한다.

## 인증 정책

- 가입 시 직군과 경력만 입력하고 바로 이용한다.
- 선생님 인증은 선택 사항이며 내 정보에서 언제든 진행할 수 있다.
- 인증 회원에게 `현직 인증` 배지를 제공한다.
- 일반 회원도 글과 댓글을 작성할 수 있다.
- 어린이집 후기는 인증 회원만 작성할 수 있다.
- 전문가 답변에는 별도의 전문가 자격 확인이 필요하다.
- 인증 자료는 커뮤니티 프로필과 분리하고 검토 후 파기한다.

## 확정 화면

| 화면 | 주요 기능 |
|---|---|
| 홈 | 네 개의 주요 영역, 최신 이야기, 검색·알림 진입 |
| 카테고리 목록 | 하위 카테고리, 정렬, 직군·경력 필터, 글쓰기 |
| 게시글 상세 | 익명·인증 정보, 원하는 반응, 공감·저장, 답변, 신고 |
| 글쓰기 | 카테고리, 제목·본문, 원하는 답변, 익명 안내 |
| 검색·필터 | 최근 검색어, 추천 주제, 카테고리·직군·경력 필터 |
| 로그인·가입 | 간편 로그인, 직군·경력 입력, 인증 건너뛰기 |
| 채용정보 | 지역·직군·고용형태 필터, 저장, 채용 제보 |
| 어린이집 후기 | 근무 인증, 근무환경 요약, 후기 작성 제한 |
| 알림 | 답변·공감·서비스 알림, 읽음 처리 |
| 내 정보 | 선택 인증, 활동, 저장 글·채용, 고객지원 |

## 디자인 원칙

- 파스텔 색상과 새싹 캐릭터를 사용한다.
- 귀여운 요소는 스티커와 아이콘에 한정하고 본문 가독성과 신뢰감을 우선한다.
- 모바일 단일 열을 기준으로 설계하고 데스크톱에서는 좌우 탐색 영역을 추가한다.
- 핵심 반응은 `위로해요`, `도움됐어요`, `저장`처럼 의미가 분명한 말로 표시한다.

## 구현 상태

Next.js MVP에는 홈, 목록, 상세, 글쓰기, 검색, 채용·후기, 알림, 내 정보, 로그인·가입의 화면 전환과 주요 UI 상호작용이 구현돼 있다. 데이터는 검증용 예시이며 로그인, 데이터베이스, 파일 업로드, 실제 검색은 다음 단계에서 Supabase와 연결한다.

## v0.3 변경 사항

- 최종 카테고리와 디자인을 확정했다.
- 교사 인증을 가입 필수에서 선택 인증으로 변경했다.
- 어린이집 후기 작성만 인증 회원에게 제한했다.
- 실제 MVP 구현 범위와 다음 연동 범위를 구분했다.
